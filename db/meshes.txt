# db/meshes.txt
# 
# List of meshes used by turf, and thier hitboxes
# 
# Structure:
# nMeshes
# mesh_id1;RAW/TRANS;where_it_is;[arguments;]
# mesh_id2;RAW/TRANS;where_it_is;[arguments;]
# mesh_id3;RAW/TRANS;where_it_is;[arguments;]
# etc
#
# mesh_id: Id of the mesh, used for
# RAW/TRANS, use RAW to load a mesh from a file, or TRANS
# to copy and transform an existing mesh.
#
# If the mesh in question is for an entity, don't transform it. If
# it is for a block, then you must transform it. (Having turf transform
# meshes at chunk building time would be slow!)
#
# Valid arguments of TRANS:
# ROT90, ROT180, ROT270, IDENTITY
# or
# x,y,z|rx,ry,rz,rang
# where (x, y, z) is the displacement, (rx, ry, rz) defines a axis of
# rotation and rang is the angle around the axis in radians
# if using ROT, define a pivot point to rotate about
#
# If using trans, the mesh being copied and manipulated must already be
# loaded.
#
# ##################################################### #####################################################
